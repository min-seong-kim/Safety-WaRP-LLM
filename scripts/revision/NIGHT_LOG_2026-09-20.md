## 미리 알고 있는 위험 (이번 세션에서 이미 겪은 것들)

1. **평가 종료 후 GPU 잔여 프로세스** — `run_all_eval.sh` 가 rc=0 으로 끝나도 자식이 GPU 를
   붙들고 남아 다음 vLLM 이 KV cache 부족으로 죽는다. batch3 는 단계마다 `wait_gpu` 로 확인하지만,
   30회(15분) 대기 후에도 안 풀리면 PID 로 정리해야 한다.
   ⚠️ `pkill -f <문자열>` 는 그 문자열이 든 내 명령까지 죽인다. ps 로 PID 를 뽑아 자기 자신을 뺄 것.
2. **Gemma lr override** — gemma2_9b 만 full-param lr 1e-5. common.sh 가 처리하지만 로그로 확인할 것.
3. **CPU offload 중 CPU 작업 금지** — 13B 가 offload 를 쓰면 CPU 작업이 학습을 4배 느리게 한다.
   (이번 batch3 는 TRAIN_ONLY_TARGETS=1 이라 13B 도 offload 를 안 쓴다)
4. **out_dir 은 하이퍼파라미터를 담지 않는다** — 같은 경로에 다시 돌리면 `.done` 때문에 건너뛴다.
   재실행이 필요하면 경로/리포명을 분리할 것. `.done` 마커를 지우지 말 것.
5. **모니터 중복** — 같은 로그에 여러 Monitor 를 걸면 알림이 겹친다. TaskStop 으로 정리.
